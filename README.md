ISS Overhead Notifier: A Python script that emails you when the International Space Station is passing overhead and it’s dark enough to see. It checks the ISS’s live position every minute using the Open Notify API, compares it to your location (within ±5° latitude and longitude), confirms it’s nighttime using the Sunrise-Sunset API, and sends an alert through Gmail’s SMTP server. Built with requests, smtplib, and datetime. Credentials are read from environment variables, and API errors are handled so it can run continuously.
